# 检索流程

    $VAULT search <库根> <关键词…>

在卡片的标题（权重 3）、主题和摘要（2）、使用说明和来源（1）里加权打分排序，`status` 为 `stale` 的排在后面。卡片零命中时自动 grep 笔记正文，返回不超过 180 字符的片段；`--deep` 强制同时搜正文。

## 怎么答

先看返回的卡片：`summary` 说清了这篇讲什么，`usage` 说清了它对用户有什么用，绝大多数问题靠这两个字段就能答，并给出笔记路径让用户自己去看。

只有用户问的是笔记里的具体细节、而卡片答不了时，才读那一篇笔记的正文。不要把命中的每篇都读一遍。

## 没找到时

- 换同义词再搜一次，中英文各试一次（库里可能存的是英文标题）
- 加 `--deep` 直接搜正文
- 都没有就如实说没找到，并问是不是当初没存进来。不要从卡片里推测一个看似合理的答案。
