# 整理流程

用户说「整理收藏夹 / 整理知识库」时走这条。**只改写卡片属性，不删除、不改写任何笔记正文。**

## 1. 列出到期笔记

    $VAULT review <库根>

默认 30 天未复核算到期，返回卡片列表（含摘要与现有使用说明）、`due_total`（到期总数，准确值）和 `has_more`。`has_more` 为 true 说明还有剩余，加 `--offset <已处理数>` 继续取。

## 2. 对齐画像

用 Read 读 `persona.md`，并问用户一句：专业、在做的项目、关注点有没有变化。有变化就先改画像文件，再往下走——整轮整理的价值几乎全在这一步。

## 3. 逐条改写使用说明

只基于卡片里的 `summary` 加最新画像来写，不读正文。

    $VAULT card <笔记.md> --usage '…'      # 自动刷新 reviewed_at

- 内容明显过时的加 `--status stale`
- 结论没变、说明也不用改的：`--touch-review`，只刷新时间
- **`summary` 不要动**。它是内容的函数，正文没变就没有理由改。真要改是当初写错了，那属于纠错，不属于整理。

## 4. 收尾

再跑一次 `review` 确认 `due_total` 归零，才 `$VAULT review --done` 关闭本轮。汇报改写条数、标记 stale 的条数、以及画像有没有更新。

周期用 `$VAULT state --set-review-days N` 调整。
